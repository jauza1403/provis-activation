# Triage Labels

Use these canonical labels in GitHub Issues:

| Role | Label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | Maintainer needs to evaluate the issue |
| Needs information | `needs-info` | Waiting for more information from the reporter |
| Ready for agent | `ready-for-agent` | Fully specified and ready for agent implementation |
| Ready for human | `ready-for-human` | Requires human implementation or decision |
| Won't fix | `wontfix` | Will not be actioned |
