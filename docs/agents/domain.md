# Domain Docs

This is a single-context repository.

Before exploring a domain area, read:

- `CONTEXT.md` at the repository root, when present.
- Relevant decisions under `docs/adr/`, when present.

If those files do not exist yet, proceed with the repository source and existing handoff notes. Do not assume missing domain documentation means the project is greenfield.

Use the vocabulary established in `CONTEXT.md` when it exists. If a needed term is absent or ambiguous, record the gap for domain-modeling rather than silently inventing a competing term.
